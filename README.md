# 🔐 ZAW GYI Ruijie Voucher Scanner

> ⚠️ For educational and authorized testing only.

## ✨ Features

- 6, 7, 8, 9 digit voucher scanning
- ASCII & alphanumeric mode support
- Auto captcha solving using ddddocr
- High concurrency (300-1000 threads)
- Real-time progress tracking

## 📦 Installation

```bash
git clone https://github.com/Zaw782/ruijie--scanner.git
cd ruijie--scanner
pip install -r requirements.txt
